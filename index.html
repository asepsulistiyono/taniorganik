Khusus pemilik kebun

Hubungkan website ke Google Sheets

Website ini sudah jadi. Agar menampilkan produk asli Anda dan menyimpan pesanan otomatis, ikuti 4 langkah di bawah. 100% gratis — hanya butuh akun Google. Setiap langkah bisa dibuka-tutup.

1 Siapkan Google Sheets

Buat spreadsheet baru di sheets.new, lalu buat 2 sheet (tab) persis dengan nama dan kolom berikut:

Tips cepat: tidak ingin mengetik manual? Setelah memasang kode Apps Script (langkah 2), jalankan fungsi setupSheets() satu kali — kedua sheet, judul kolom, dan 3 produk contoh akan dibuat otomatis.

2 Pasang kode Google Apps Script
  1. Di spreadsheet, menu Extensions → Apps Script (tab baru terbuka).
  2. Hapus semua isi editor, lalu tempel seluruh kode di bawah (tombol Salin kode ada di kanan atas kotak kode).
  3. Ganti SHEET_ID dengan ID spreadsheet Anda — ada di alamat URL, di antara /d/ dan /edit.
  4. Klik ikon Simpan (gambar disket di toolbar) atau tekan Ctrl+S.
Code.gs — tempel di script.google.com
3 Deploy sebagai Web App
  1. Di editor Apps Script, klik Deploy → New deployment → pilih tipe Web app.
  2. Isi: Description = “API Kebun v1”.
  3. Execute as: Me (akun Anda).
  4. Who has access: Anyone — ini wajib agar website bisa mengakses.
  5. Klik Deploy, lalu Authorize access (izinkan akses saat diminta — pilih akun Google Anda, klik Advanced → Go to project).
  6. Salin Web App URL — bentuknya https://script.google.com/macros/s/AKfycb…/exec.
  7. Uji di browser: buka URL-anda/exec?action=ping dan URL-anda/exec?action=produk. Jika muncul teks JSON, API berhasil jalan.

Penting: setiap kali mengubah kode, ulangi deploy dengan Deploy → Manage deployments → ✏️ Edit → Version: New version, lalu Deploy lagi. URL tetap sama.

4 Hubungkan ke website ini
  1. Buka file script.js website ini. Di bagian paling atas ada baris:
    const API_URL = "[ISI_DISINI]";
  2. Ganti [ISI_DISINI] dengan Web App URL dari langkah 3 (akhiran /exec).
  3. Ganti juga WA_NUMBER di baris bawahnya dengan nomor WhatsApp kebun Anda (format 62xxx).
  4. Ganti nama kebun, alamat, dan nomor WA di index.html — cari komentar [GANTI].
  5. Muat ulang website — banner “mode demo” hilang, dan produk tampil dari Google Sheets Anda. Coba pesan: data masuk ke sheet Pesanan.

Hosting gratis (agar bisa diakses pembeli)

Website ini hanya 3 file (index.html, style.css, script.js) — unggah gratis ke GitHub Pages, Netlify Drop (tinggal seret folder ke netlify.com/drop), atau Vercel. Selesai — website Anda online tanpa biaya server.

Update stok sehari-hari: cukup ubah angka di kolom Stok dan Status sheet Produk — website langsung mengikuti. Tambah jenis panen musiman? Tambah baris baru saja.
